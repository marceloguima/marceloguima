## 🚀 Sobre Mim

Como estudante, meu objetivo é transformar ideias em **aplicações web funcionais e visualmente agradáveis**.  
Acredito que uma boa **interface de usuário (UI)** combinada com uma excelente **experiência do usuário (UX)** são essenciais para o sucesso de qualquer projeto.

Nos meus projetos acadêmicos e pessoais, venho desenvolvendo uma base sólida em:

- **Desenvolvimento Front-End Moderno:** Interfaces dinâmicas, responsivas e otimizadas para todos os dispositivos.
- **Manipulação do DOM com JavaScript Puro:** Interatividade, atualização em tempo real e controle do estado da aplicação.
- **Lógica de Componentes:** Estruturação de código limpa, reutilizável e bem organizada.
- **Resolução de Problemas (Debugging):** Depuração de código e correção de bugs, tanto em lógica quanto em estilo.

Estou constantemente aprendendo novas tecnologias e buscando melhorar minhas habilidades com projetos práticos.
